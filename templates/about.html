Hybrid Multimodal Context-Aware Personalized Fashion Recommendation System Using Machine Learning and Computer Vision

Problem and objective

A category prediction followed by arbitrary product selection offers limited personalization. This demonstration ranks available catalog items against supported profile and context inputs and exposes why an item was ranked.

Recommendation engine

The application uses deterministic content-based scoring with product category, season, gender, location, color, brand, rating, discount, stock and supported profile preferences. The score is a relevance score, not a probability.

Personalization and context

Supported profile and fashion preferences contribute to product ranking. Open-Meteo current weather may adjust ranking; if lookup fails, recommendations can continue with profile and season inputs.

Computer vision

Optional OpenCV and MediaPipe Pose processing estimates limited image-based proportions and an experimental styling category. It is not a validated classifier or an objective or medical body-shape determination; no confidence score is produced.

Machine learning and evaluation

A Random Forest category classifier is retained as an evaluated baseline. The deployed recommendation path is the content-based ranker. Offline ranking metrics use held-out catalog proxy relevance because the dataset has no user-item interactions.

View the generated evaluation results

Implementation

Python, Flask, Pandas, NumPy, scikit-learn, SQLite, OpenCV, MediaPipe Pose and Matplotlib support the implemented workflow and evaluation artifacts.

Data and privacy limitations

The catalog does not provide product photos, fabric-weather properties, or user interaction history. Uploaded images are processed in memory; the image is not retained in the workflow store. No login is required.

Current scope

Age and occasion are not collected because they are not supported recommendation inputs. Evaluation results do not establish user satisfaction or the effectiveness of weather and body-shape adjustments.
